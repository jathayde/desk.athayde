**Findings**

1. Auto-relist is too eager. [positions_job.rb](/Users/jathayde/Development/Personal/desk.athayde/app/jobs/sync/positions_job.rb:23) relists from `row.last_price`, which is just `marketValue / quantity` from the positions payload, with no quote timestamp or freshness proof. A stale positive market value can immediately undo an operator delist on the next sync, causing operator/system flapping. Before commit, relist only from a fresh explicit quote/price signal, or require a separate operator relist.

2. The morning brief/tool layer can still expose prices for delisted symbols. The system prompt says “never quote them” [system.md.erb](/Users/jathayde/Development/Personal/desk.athayde/app/models/agent/prompts/system.md.erb:27), but `get_portfolio` still returns `last_price`, `market_value`, `unrealized_pnl`, `distance_to_stop`, and `open_risk` fields for every row [get_portfolio.rb](/Users/jathayde/Development/Personal/desk.athayde/app/models/agent/tools/get_portfolio.rb:24), and `get_quotes` does not reject delisted symbols [get_quotes.rb](/Users/jathayde/Development/Personal/desk.athayde/app/models/agent/tools/get_quotes.rb:12). Enforce this in tools, not just prompt text.

3. `Agent::Context#delisted_symbols` lists all delisted instruments, not current held delisted positions [context.rb](/Users/jathayde/Development/Personal/desk.athayde/app/models/agent/context.rb:39). Since complete position sync deletes absent positions [positions_job.rb](/Users/jathayde/Development/Personal/desk.athayde/app/jobs/sync/positions_job.rb:30), a sold/removed instrument can be announced forever as a “Delisted holding.” Scope through trading-account positions.

4. The controller is authenticated and gets normal Rails CSRF via `ApplicationController`, but authorization/scoping is too broad: any signed-in session can PATCH any `Instrument` id [instruments_controller.rb](/Users/jathayde/Development/Personal/desk.athayde/app/controllers/instruments_controller.rb:3), and any non-`"1"` param relists [instruments_controller.rb](/Users/jathayde/Development/Personal/desk.athayde/app/controllers/instruments_controller.rb:4). Scope to current trading holdings and validate `delisted` as `"0"`/`"1"`.

Dashboard/excluded summary/snapshot mostly handle `:delisted`, but Playwright lacks a delisted scenario, and the dashboard can still prefer old distance-to-stop text over the delisted label when stale prices exist [\_glance.html.erb](/Users/jathayde/Development/Personal/desk.athayde/app/views/dashboard/_glance.html.erb:36). Journal behavior appears consistent with the design: open trades and review flags remain.
